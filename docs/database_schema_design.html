RLS enabled on every durable crucible table

Schema Overview

Purpose

crucible stores product truth: research programs, append-only hypothesis DAG nodes, runs, claims, approvals, budgets, and durable events.

Runtime Separation

lg_checkpoints is reserved for LangGraph checkpoint state. It is runtime state, not product truth.

Security Boundary

The schema revokes anon and authenticated access. Server-side FastAPI access uses DATABASE_URL.

Extensions

pgcrypto supplies UUID defaults and vector powers semantic recall over claim embeddings.
